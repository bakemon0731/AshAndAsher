## 概要

本作はGameplayAbilitySystemを使用したゲームで、主にC++で開発しています。

本リポジトリはポートフォリオにおけるC++ソースコードの評価用として公開しています。

Unreal Engine プロジェクト特有のファイルサイズ肥大化（アセット等のバイナリデータ）を考慮し、本リポジトリでは純粋な C++ のソースコード（ソースディレクトリ等）のみをバージョン管理しています。

## 技術的なアピールポイント（C++実装における設計の工夫）

### 1. GAS（Gameplay Ability System）を用いたスケーラブルな能力・属性管理

ゲーム規模の拡大を見据え、キャラクターのスキルやステータス管理にUE標準のフレームワークであるGASを導入しています。

- **Fatクラスの回避**: ダメージ処理やスキル発動ロジックをキャラクタークラスに直接書くのではなく、`GameplayAbility`としてカプセル化することで、キャラクタークラスの肥大化を防ぎます。
- **プロパティ管理**: `CombatAttributeSet` などを定義し、HPや攻撃力などのステータスを一貫したルールのもとで安全に管理・運用できる仕組みを構築しました。

### 2. イベント駆動によるパフォーマンスを意識したAI実装

ビヘイビアツリー（Behavior Tree）における条件判定やタスク実行を、Tickによる毎フレームの監視（ポーリング）ではなく、イベント駆動（Delegate）で実装しています。

- **カスタムデコレーターの作成**: `UBTD_StateGameplayTag` では、対象のGameplayTagが付与・削除された瞬間にだけ再評価をリクエスト（`RequestExecution`）するよう実装し、CPU負荷の軽減を図っています。
- **安全なメモリ管理**: BTノード特有のインスタンスごとのメモリ構造体（`FNodeMemory`）を定義し、さらに`TWeakObjectPtr`を使用することで、安全かつ効率的なメモリ管理を行っています。

### 3. ネットワークマルチプレイへの対応と正当な権限管理

オンラインプレイを前提としたネットワークマルチ処理をC++で実装しています。

- **サーバー権限（Authority）の徹底**: ダメージ計算、ステータスの追加など、ゲームの進行に重要なロジックは必ずサーバー側（`HasAuthority()`）で処理し、チートや同期ズレを防ぐ適切な設計をしています。
- **レプリケーションと同期**: `GetLifetimeReplicatedProps` を用いて同期が必要な変数（HPやスタミナ、装備中の武器情報など）のみを正しくレプリケーションし、`OnRep`関数を利用してクライアント側での表示更新（UIやアニメーション）をフックさせる処理を実装しています。

### 4. 拡張性を意識したコンポーネント指向なアーキテクチャ

機能ごとに`ActorComponent`へ分割し、オブジェクト間の疎結合な設計を実現しています。

- **TargetSystemComponent**: ロックオン対象の判定、カメラのViewport内外の判定、LineTraceによる遮蔽物判定、およびプレイヤーの回転制御（`bOrientRotationToMovement`と`bUseControllerRotationYaw`の動的切り替え）のロジックを独立したコンポーネントとして実装しています。
- **WeaponComponent / WeaponBase**: 武器の生成・装備と、ヒットスキャン（複数のトレースを用いた連続処理）などの武器固有の動作管理を分離し、新しい武器種を追加しやすい構造にしています。

## 📁 評価していただきたい主要なクラス

コードレビューの際の参考として、アーキテクチャの根幹となる主要なクラスをピックアップしました。

| クラス | 概要 |
|---|---|
| [`DamageCalculationModifier.cpp`](Source/GAS/GameplayAbilitySystem/Effects/DamageCalculationModifier.cpp) | GASのカスタム計算クラス。ターゲットの鎧とソースの強さを動的にキャプチャし、計算式に基づいてダメージを適用するロジックです。 |
| [`BTD_StateGameplayTag.cpp`](Source/GAS/AI/BTD_StateGameplayTag.cpp) | ビヘイビアツリーのカスタムデコレーター。Tickを使わずに、ASCのGameplayTagの変更をDelegateで監視するイベント駆動の仕組みを実装しています（メモリ構造の管理も行っています）。 |
| [`BTT_Attack.cpp`](Source/GAS/AI/BTT_Attack.cpp) | ビヘイビアツリーからC++経由でGASの`GameplayAbility`を直接発動させ、開始・終了イベントをコールバックで受け止めるカスタムタスクです。 |
| [`AC_TargetSystemComponent.cpp`](Source/GAS/TargetSystem/AC_TargetSystemComponent.cpp) | ロックオンシステムを制御するコンポーネント。 |
| [`WeaponBase.cpp`](Source/GAS/Weapon/WeaponBase.cpp) | 武器の基底クラス。DelegateやTimerManagerを利用したヒットスキャンの制御や、ヒットした対象へのGameplayEffect（ダメージやデバフ）の適用処理を実装しています。 |
